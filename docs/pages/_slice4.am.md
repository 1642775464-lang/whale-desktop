## 两个「看着好好的，其实没工作」的 bug

这一片抓到两个**自己写出来的**缺陷，都属于最难发现的那类——元素都在、宽度正常、没有任何报错。

```callout
两个 bug 都是加了一条更严格的断言才暴露的
```

**第一个：滚筒首帧从不绘制。** A4 原本只查「元素在不在、宽度大不大」，那样是**通过**的。我加了一条「标题必须真的画出会话名，不能停在占位符」，立刻红了：标题永远停在 `–`。原因是多会话时 `update()` 只负责排期，从不画当前项——界面看着齐全，实际一个字都没显示。

**第二个：桥断了但界面不降级。** 验收降级路径时发现点是灰的、标题是 `–`，而不是红点加空态文案。原因是 `markOffline()` 写成「已经是 offline 就 return」，而 `state.offline` 的**初值就是 true**——于是第一次连不上时永远不会通知界面。

> 这两个都印证了同一件事：**断言太宽松等于没有断言**。第一个如果我只查元素存在，它会一直绿着上线。

## 一处架构偏离，需要你知道

《轻量架构草案》说几何要「物理像素走 HWND + `GetWindowRect`」。**零运行时依赖下做不到**——读物理矩形需要 FFI，而强制 17 规定运行时依赖为 0。

改法是全程用 Electron 的 DIP。理由：A1 判据里的 `workArea` 与 `setBounds` 收的都是 DIP，**两侧同量纲，居中计算自洽**。实测居中误差 0px。这处偏离已记入 S4-D1 与 STATUS。

## 一处决策补全，需要你确认

《前端设计规范》3.8 写了收展的几何与 3px 阈值，但**没说展开由什么触发**——这是个真空档。PRD F2① 只规定「单击鲸鱼 = 唤起小窗」。

我取的是**双击球展开**，把单击留给 PRD 已定的语义。这是我补的默认值，不是条文里的规定。若你想换成单击展开（或右键菜单里加一项「展开」），改 `hud.js` 的 `bindDrag` 里那一个分支即可。

```kv

新增工具: 图标机械内联、桥独立开发服务器、验收探针
```

**为什么要专门写一个桥的独立开发服务器**：桥是 Cordis 插件，靠宿主 `apply(ctx)` 启动，**没有独立入口**。不写它，前端就没有真桥可连，验收只能手搓假数据——那验的是假数据，不是桥真的这么回。

**为什么验收探针不用 CDP**：零依赖下手写 WebSocket 客户端是纯风险。协议层一旦写错，表现就是「连不上」。而「连不上」与「界面有问题」在报告里长得一模一样，很容易把探测器故障当成产品故障。Electron 主进程本身就能 `executeJavaScript`、读 `getBounds()`、收 `console-message`，三样都够，且没有可错的协议层。
