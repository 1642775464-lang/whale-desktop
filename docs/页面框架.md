## 一、三件套与它们的关系

```
┌───────────────────────────────────────────────────────────┐
│  浏览器里的 DSH 主窗                                        │
│                                                            │
│   右下角 ┌─────┐  whale-button（客户端插件）                 │
│         │ 🐋  │  单击 → 同时 /whale/open ×2                 │
│         └─────┘                                            │
└──────────────────┬────────────────────────────────────────┘
                   │ HTTP
                   ▼
┌───────────────────────────────────────────────────────────┐
│  DSH 宿主进程                                               │
│                                                            │
│   whale-bridge（Cordis 插件）  ← 唯一的"知情者"              │
│   ├─ 订阅 ctx.sessions 的 session/event                     │
│   ├─ 两份折叠器：hudBySession / sessionFold                  │
│   └─ HTTP + SSE @ 127.0.0.1:19387                          │
└───────┬─────────────────────────────┬─────────────────────┘
        │ GET /whale/hud + /hud/events│ GET /whale/events + /panel
        ▼                             ▼
┌───────────────────┐        ┌───────────────────┐
│  whale-hud        │        │  whale-window     │
│  悬浮条 588×72     │        │  小窗 492×710      │
│  独立 Electron     │        │  独立 Electron     │
└───────────────────┘        └───────────────────┘
```

**两个 Electron 进程刻意独立**：

- 关掉悬浮条不该影响小窗，反之亦然
- 同一进程里做多窗会让"退出"语义变含糊（关哪个？）
- 单实例锁、`userData` 目录、托盘都要各自独立

## 三、悬浮条（HUD）页面框架

### 3.1 展开态（P1）· 窗口 588×72

```
┌─ 窗口 588×72 （透明，仅可见 560×52 的条） ────────────────────┐
│  ←14px→                                                      │
│        ┌──────────── 条 560×52 · 胶囊 r26 ────────────────┐  │
│        │ ┌──────┐  ●  继续开发豆包式小窗口   38.2 tok/s  193k  ‹ │  │
│        │ │ 🐋   │  ↑点    ↑标题(滚筒)          ↑速度    ↑上下文 ↑收起│
│        │ │40×40 │                                              │  │
│        │ └──────┘                                              │  │
│        └─────────────────────────────────────────────────────┘  │
│                                                    ↑ y=6        │
└──────────────────────────────────────────────────────────────┘
                  条内图标 x=22 y=12，中心 (42,32)
```

**DOM 结构**：

```html
<body class="hud">
  <div class="stage">                    <!-- 撑出 588×72 的透明舞台 -->
    <div class="bar" id="bar">
      <div class="whale" id="whaleBtn">   <!-- 单击唤起/收起小窗 -->
        <svg class="ico-whale">…</svg>
      </div>
      <div class="seg grow">
        <span class="dot" id="dot"></span>
        <div class="reel" id="reel">
          <span class="face" id="faceB"></span>   <!-- back 在下层 -->
          <span class="face" id="faceF"></span>   <!-- front 在上层，DOM 在后 -->
        </div>
      </div>
      <div class="seg mono" id="segSpeed"><span class="val" id="spdVal">–</span><span class="unit">tok/s</span></div>
      <div class="seg mono ctx" id="segCtx"><span class="val" id="ctxVal">–</span></div>
      <button class="collapse-btn" id="collapseBtn">…‹…</button>
    </div>
  </div>
  <div class="popover" id="hudDetail" hidden>…五行…</div>
</body>
```

> **`faceB` 必须在 `faceF` 之前**（DOM 顺序决定堆叠，`front` 更上层）。写反了 A7 会闪假标题。

### 3.2 悬停详情（P3）· 窗口 588×340

```
┌─ 窗口 588×340 ────────────────────────────────┐
│  ┌──── 条 560×52（位置不变 y=6）──────────┐   │
│  │ 🐋  ● 标题            86.6 tok/s  193k ‹│   │
│  └────────────────────────────────────────┘   │
│           ┌── 详情 270px（top:88） ──┐          │
│           │ 上下文占用        193,442 │          │
│           │ 累计输出           12,884 │          │
│           │ 累计输入           86,210 │          │
│           │ 累计缓存读        402,118 │          │
│           │ 步数 / 回合      418 / 112│          │
│           └──────────────────────────┘          │
└───────────────────────────────────────────────┘
```

- 显示：`mouseenter` → `win.setBounds({height:340})`
- 隐藏：`mouseleave` 后 `180ms` → 缩回 `72`
- 兜底：`3000ms` 定时器强制缩回
- **不做常驻高窗口**（透明像素不拦截鼠标之外的穿透问题 → 隐形点击陷阱）

### 3.3 球形态（P2）· 窗口 88×88

```
┌─ 窗口 88×88 ──────────┐
│      ┌────────┐       │
│      │   🐋   │ 40×40 │   ← 球在窗口内 x=24 y=12
│      └────────┘       │
└───────────────────────┘
```

**收展动画**：

- 收起：条 `transform: scaleX(0)`，`transform-origin: left center`，`275ms`
- 展开：从图标右边缘向右长出，`335ms`
- **图标全程不动**：收起时把 `#whaleBtn` 从 `.bar` **物理 `appendChild` 到 `document.body`**，展开时插回原位
  （原因见《前端设计规范》第七节陷阱 3）

## 六、数据流

### 6.1 悬浮条数据流

```
宿主 session/event
   ↓ (session, event)
桥 hudBySession 折叠（不设 tail，按 seq 水位去重）
   ↓
GET /whale/hud           全量快照（首次 + 断线重连）
GET /whale/hud/events    SSE 增量
   ↓
hud.js 渲染：点 / 标题 / 速度 / 上下文
```

速度由桥每 `2000ms` 心跳重算（窗口 `SPEED_WINDOW_MS = 8000`）。

### 6.2 小窗数据流

```
宿主 session/event
   ↓
桥 sessionFold（保留最近 40 条渲染事件）
   ↓
GET /whale/panel?sessionId=xx   初始全量
GET /whale/events                SSE 增量（带 Last-Event-ID 续传）
   ↓
app.js 渲染消息流 / 任务坞 / 状态条
```

### 6.3 用户操作 → 宿主

| 操作 | 请求 | 宿主效果 |
|---|---|---|
| 发消息 | `POST /whale/send` | 真进入会话；回合运行中自动 `mode:"queue"` |
| 中断 | `POST /whale/abort` | 取消**本会话**正在跑的 agent（有护栏） |
| 切权限 | `POST /whale/command` `{cmd:"/permission workspace-write"}` | 不经模型 |
| 切会话（可切换） | `POST /whale/activate` | 立刻切换 |
| 切会话（历史） | `POST /whale/resume` | 唤醒后切；标签显示「唤醒中 Ns」 |
| 唤起小窗 | `POST /whale/open` | 存活则复用，否则 spawn |
| 关闭小窗 | `POST /whale/close` | 关自己拉起的进程 |

## 八、模块边界（谁能改谁）

| 模块 | 职责 | 不许做的事 |
|---|---|---|
| `whale-bridge` | 唯一数据源；HTTP/SSE；拉窗 | 不渲染 UI；不持凭证 |
| `whale-hud` | 只读展示 | 不发消息、不执行命令 |
| `whale-window` | 读写会话 | 不直连宿主（只走桥） |
| `whale-button` | 页面浮层入口 | 不做窗口逻辑 |

**两个 Electron 都不 `require` 宿主模块** —— 只通过 HTTP 说话。
