### 1.5 阴影（三层，缺一不可）

**悬浮条 / 小窗共用同一组三层阴影**：

```css
box-shadow:
  0 1px 2px  rgba(20,30,60,.05),
  0 8px 22px rgba(40,55,110,.10),
  0 18px 40px rgba(40,55,110,.06);
```

小窗 `.win` 用稍重的一组（因为它更大）：

```css
box-shadow:
  0 8px 24px rgba(30,45,90,.13),
  0 24px 56px rgba(30,45,90,.09),
  0 0 0 1px   rgba(120,130,175,.14);
```

> **第三层 `0 0 0 1px` 是描边不是阴影** —— 它让白底在浅色桌面上仍有轮廓。
> 悬浮条对应的描边是 `border: 1px solid rgba(120,130,175,.20)`。

**为什么必须靠阴影而不是原生阴影**：见《悬浮窗-PRD》5.x —— Windows 对无边框透明窗不画原生阴影，`hasShadow` 必须 `false`，
阴影只能画在窗口矩形内部，所以窗口必须比可见内容大一圈（`SHADOW_PAD`）。

## 二、关键词汇与"不许自创"清单

用户已明确裁定过的视觉决策，**不得重新提议**：

| 决策 | 裁定 |
|---|---|
| 震动提醒 | **位移类**，不是脉冲。脉冲已被用户否决 |
| 收起 / 展开模型 | 球就是条左端那个图标，**全程不动**；不是"条与球互相替换" |
| 悬停详情 | 只在 `:hover` 时临时加高，**不做常驻高窗口**（透明像素不穿透，会成点击陷阱） |
| 图钉图标 | 真图钉剪影：顶部宽横帽 + 梯形身 + 针 |
| 圆角 | 窗口透明 + CSS 裁角；`roundedCorners: false` |
| 毛玻璃 | **不做**（实测方差比 0.935 ≈ 没模糊） |
| 顶栏按钮 | 语音 / 麦克风 / 屏幕共享三个占位按钮**已删**，不得加回 |
| 灰色项 | 灰 = 能力未接通，点击**不得有任何静默效果**：不假装能用 |

## 三、悬浮条（Whale HUD）

### 3.1 几何

| 形态 | 窗口 | 内容 |
|---|---|---|
| 展开（条） | `588 × 72` | 条 `560 × 52`，条在窗口内 `x=14, y=6` |
| 收起（球） | `88 × 88` | 球 `40 × 40`，球在窗口内 `x=24, y=12` |
| 悬停（详情） | `588 × 340` | 条仍在 `y=6`，详情浮层 `top: 88px`、宽 `270px`、水平居中 |

**图标在条内的位置**：`x=22, y=12`，`40×40`；中心 `(42, 32)`。
**球在窗口内的位置**：`x=24, y=12`。

> 两态图标屏幕坐标必须一致（实测都是 `36`）。这是 A9 的验收判据。

### 3.2 条的结构（从左到右五元素）

```html
<div class="bar">
  <div class="whale on"><svg …/></div>          <!-- ① 鲸鱼头像 -->
  <div class="seg grow">
    <span class="dot run"></span>               <!-- ② 状态点 -->
    <span class="reel"><span class="reel-item">会话标题</span></span>  <!-- ③ 标题 -->
  </div>
  <div class="seg mono"><span class="val">38.2</span><span class="unit">tok/s</span></div>  <!-- ④ 速度 -->
  <div class="seg mono"><span class="val">193k</span></div>                                  <!-- ⑤ 上下文 -->
  <button class="collapse-btn"><svg …/></button>  <!-- 收起箭头（朝左） -->
</div>
```

CSS 关键值：

```css
.bar{height:52px;border-radius:26px;padding:0 12px 0 8px;gap:10px;
     background:linear-gradient(180deg,#FFFFFF,#FDFDFF);
     border:1px solid rgba(120,130,175,.20);}
.seg.grow{flex:1 1 auto;min-width:0;height:36px;border-radius:9px;
          display:flex;align-items:center;gap:9px;padding:0 10px;}
.seg.mono{flex:0 0 auto;height:36px;padding:0 10px;display:flex;
          align-items:baseline;gap:4px;font-family:var(--mono);font-size:15px;font-weight:600;}
```

**收起箭头方向**：`polyline points="15 18 9 12 15 6"` —— 朝**左**。用户明确点名改过方向，不得改回朝右。

### 3.3 鲸鱼头像

```css
.whale{width:40px;height:40px;border-radius:50%;flex:0 0 40px;
       background:var(--soft);
       border:1px solid rgba(120,130,200,.30);
       box-shadow:0 0 0 1px rgba(120,130,200,.10), 0 2px 8px rgba(90,100,180,.18);
       display:grid;place-items:center;}
.whale svg{width:24px;height:24px;display:block;}
.whale.on::after{content:'';position:absolute;inset:-3px;border-radius:50%;
                 border:2px solid rgba(34,197,94,.85);}   /* 外圈绿环 = 小窗在跑 */
```

**SVG 来源**：`whale-hud/renderer/favicon-whale.svg`（从 DSH 官方 favicon 复制，3634 字节）。
原文件带 `fill="#000"`，**用 CSS 覆盖颜色**，不要手改路径：

```css
.whale svg path{fill:var(--ink);}
```

行为：**单击唤起小窗；小窗已在跑时再点收起**（与入口按钮行为一致，不是重复拉起）。

### 3.4 状态点（三种）

判据是 `speed.phase`，**不是"最近有没有出 token"**。

| 类 | 外观 | 含义 |
|---|---|---|
| `.dot.run` | `--ok` + `box-shadow: 0 0 0 4px rgba(34,197,94,.16)` | 回合在跑（含工具执行阶段） |
| `.dot.idle` | `--dot-idle` `#C8CDDB` | 空闲 |
| `.dot.bad` | `--bad` + `box-shadow: 0 0 0 4px rgba(239,68,68,.14)` | 桥连不上 |

```css
.dot{width:8px;height:8px;border-radius:50%;flex:0 0 8px;}
```

**桥连不上时所有数值显示 `–`**，不伪造上一次读数。

### 3.5 速度数字

- 正常：`--ink`，等宽，`15px/600`
- 回合结束：加 `.grey` → `--ink3`，数值**冻结**在最后一次（你还能看到刚才跑多快）
- 桥断开：显示 `–`

### 3.6 上下文数字

- 显示简短形式：`193k`（≥1000 时用 `k`，保留 1 位有效小数，四舍五入到整数位）
- **悬停该段** → 窗口加高到 `340px`，弹出五行详情浮层

浮层规格：

```css
.popover{position:absolute;left:50%;transform:translateX(-50%);top:88px;
         width:270px;background:#fff;border:1px solid var(--line);
         border-radius:12px;box-shadow:0 10px 30px rgba(40,55,110,.14);
         padding:12px 14px;}
.popover .row{display:flex;justify-content:space-between;
              padding:5px 0;font-size:13px;border-bottom:1px solid #F1F3F9;}
.popover .row:last-child{border-bottom:0;}
```

五行（**顺序固定**）：

| 行 | 取值 |
|---|---|
| 上下文占用 | `contextUsed`（= `contextPressure.projectedTokens`） |
| 累计输出 | `totalOutput` |
| 累计输入 | `totalInput` |
| 累计缓存读 | `totalCacheRead` |
| 步数 / 回合 | `steps / turns` |

数字格式：千分位，等宽，`--ink` 加粗；标签 `--ink2`。

**缩回规则**：移出 `180ms` 内缩回；另有 `3000ms` 兜底定时器（防止鼠标飞出窗口后 never 收到 `mouseleave`）。

### 3.7 多会话滚筒

**触发条件**：`speed.phase === 'running'` 的会话 ≥ **2** 个。

| 阶段 | 时长 |
|---|---|
| 停留 | `3000ms` |
| 上半程（旧标题翻下去） | `250ms` |
| 下半程（新标题翻上来） | `250ms` |
| 整周期 | `3500ms` |

动画：`rotateX`，上半程 `ease-in`，下半程 `ease-out`。

**实现铁律（A7 判据：不得闪出"下一个的下一个"）**：

1. 两个面 `front` / `back`，DOM 顺序 **`front` 在 `back` 之后**（`front` 更上层）
2. `swapAt`（`250ms`）回调里**只改 `front`，刻意不碰 `back`**
3. 下半程**先清 `front` 的类/样式**（`transition:none; opacity:0; rotateX(90deg)`），
   此时 `front` 恢复 `opacity:1` 靠 DOM 顺序盖住 `back`，**然后**才改 `back`
4. 顺序反了会有 `16ms` 的可见窗口闪出错误标题

**两个防御机制（踩坑后加的，不得删）**：

| 机制 | 作用 |
|---|---|
| DOM 代际号 `reelGen` | 翻转由两个定时器驱动，中途若重建 DOM，旧定时器会改**已脱离文档的孤儿节点**（表现：翻转卡住且无报错）。代际号让过期回调自行作废 |
| `rolling` 看门狗 | `rolling` 是防重入互斥锁；万一有路径绕过（定时器降频、异常中断），会永久停在 `true`（表现：标题再也不动且毫无报错）。看门狗强制放掉 |

**锁定**：

- 单击标题锁定，右侧出 `🔒`；再点解锁
- 悬停出下拉列全部进行中会话，当前显示项高亮
- 点下拉项会跳转并**顺手锁定**（否则 3 秒后又翻走）
- **会话掉到 1 个时锁自动清除**（否则出现"只剩一个会话、🔒 还挂着"，锁无法解释、点了也没反应）

### 3.8 收起 / 展开

**核心模型（用户裁定）**：球就是条左端那个图标，全程不动。
收起 = 其余部分缩回图标右边缘；展开 = 从那里向右长出。**不是"条与球互相替换"**。

- 终点由 `.collapsed` 自己声明 `transform: scaleX(0)`
- 收起态 `overflow: visible`（否则后代全被裁）
- **图标必须从条里物理挪到 `document.body`**（详见第七节"祖先 transform"陷阱）
- 拖动阈值 `3px`（小于等于 3px 算单击）

### 3.9 完成提醒

回合结束时：

1. 标题框显示**对应会话标题**（不是当前显示的那个）
2. 悬浮条**小幅震动，持续 2000ms**
3. 震动是**位移类**，不是脉冲

## 四、小窗（Whale Window）

### 4.1 几何

| 项 | 值 |
|---|---|
| 内容 | `460 × 678` |
| 窗口 | `492 × 710` |
| 投影边距 `SHADOW_PAD` | `16` |
| 圆角 | `18px` |
| 顶栏 | `42px` |

```css
.win{width:460px;height:678px;border-radius:18px;background:#fff;
     display:flex;flex-direction:column;overflow:hidden;font-size:12.5px;}
```

**窗口外扩的实现**：

```css
body{padding:var(--shadow-pad);}   /* --shadow-pad 必须等于 SHADOW_PAD=16 */
```

> `SHADOW_PAD`（主进程）与 `--shadow-pad`（`skin.css`）**必须完全一致**。不一致时：
> 窗口留小 → 阴影被硬切一条直边；留大 → 窗外多一圈无用途空边，且"窗口矩形"与"可见小窗矩形"错位，钳制/吸边全不准。

### 4.2 顶栏（42px）

从左到右：

| 顺序 | 元素 | 说明 |
|---|---|---|
| 1 | `−` 最小化 | |
| 2 | **图钉** | 钉住 / 取消钉住 |
| 3 | 工作区色块 `.brand-dot` | `7×7` 圆，`linear-gradient(135deg,var(--brand),var(--brand2))`，占位 |
| 4 | 会话标题 `.tb-title` | `flex:1 1 auto; text-align:center` → **标题永远居中** |
| 5 | `⚙` 齿轮 | 侧边工作台 |
| 6 | `☰` | 更多 |

```css
.topbar{height:42px;flex:0 0 42px;display:flex;align-items:center;
        padding:0 10px;gap:8px;border-bottom:1px solid #F0F2F8;
        -webkit-app-region:drag;}
.ico{width:24px;height:24px;border:0;background:transparent;border-radius:6px;
     display:grid;place-items:center;color:var(--ink2);cursor:pointer;padding:0;}
.ico svg{width:15px;height:15px;display:block;}
.ico:hover{background:#F2F4FA;}
.tb-title{flex:1 1 auto;text-align:center;font-size:12.5px;color:var(--ink2);
          white-space:nowrap;overflow:hidden;text-overflow:ellipsis;}
```

**顶栏本身就是拖拽区**（无边框窗口需渲染层把位移交给主进程），故按钮必须 `-webkit-app-region: no-drag` 或自行 `stopPropagation`。

### 4.3 图钉图标（v2 真图钉剪影）

```html
<svg viewBox="0 0 16 16" fill="none" stroke="currentColor" stroke-width="1.3"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M4.6 3.2h6.8v1.7H4.6z"></path>   <!-- 宽横帽：必须用 path，不能用 rect -->
  <path d="M5.6 4.9h4.8l-.9 4.4H6.5z"></path>
  <path d="M8 9.3v3.5"></path>              <!-- 针 -->
</svg>
```

> **横帽必须用 `<path>` 写闭合矩形而不是 `<rect>`** —— 全局 `.ico svg rect { fill:none }` 会把它清成空心。
>
> 历史：旧图 path 宽仅 4.8（占画布 30%），在按钮里就是一根细竖条，用户反馈"过于窄了"。
> v1 用"圆头 + 梯形身 + 细针"，放大后仍像小人/奖杯。v2 才是真图钉。

### 4.4 会话标题行

```html
<div class="session-head">
```

## 七、已知陷阱（实现必读，全部是实测踩出来的）

| # | 陷阱 | 后果 | 正确做法 |
|---|---|---|---|
| 1 | 摘掉动画类会连 `forwards` 填充一起消失 | 条弹回 560px，被 88px 窗口裁出"蓝紫渐变残影" | 终态必须由 `.collapsed` 自己声明 `transform: scaleX(0)` |
| 2 | `overflow: hidden` 对**所有**后代生效（含 `position: fixed`） | 收起态图标被裁 | 收起态必须 `overflow: visible` |
| 3 | **祖先自带 `transform` 就成为后代的包含块** | 后代 `position: fixed` 不再相对视口；条的 `scaleX(0)` 把图标压成 0 宽（实测 `whale.w = 0`），`position:fixed` / `z-index` / `overflow:visible` 全救不了 | **收起时把图标从条物理挪到 `document.body`**，展开时按原位插回 |
| 4 | 只写 `script-src 'unsafe-inline'` | `<script src="hud.js">` 被**静默拦截**，窗口里只剩 HTML 字面文本，除渲染进程控制台外无任何报错 | CSP 必须放行 `'self'` |
| 5 | 全局 `.ico svg rect { fill:none }` | 图钉横帽被清成空心 | 横帽用 `<path>` 写闭合矩形 |
| 6 | `node --check` 只查语法，**查不出 TDZ** | 自检里 `cs.boxShadow` 写在 `const cs = …` 之前 → 整个自检中断 | client 侧 JS 改动**必须实地跑** |
| 7 | 滚筒两个面同时透明还不够 | 必须保证**同一个可见面上的文字不被中途改写** | `swapAt` 只改 `front`；下半程先清类再改 `back` |
| 8 | 重入锁无兜底 | `rolling` 永久停在 `true` → 标题再也不动且毫无报错 | 看门狗强制放掉 |
| 9 | 定时器 + DOM 重建 | 旧定时器改**已脱离文档的孤儿节点** → 翻转卡住且无报错 | DOM 代际号 `reelGen` |
| 10 | 透明窗口在 Windows 上**仍拦截鼠标事件**（透明像素不穿透） | 常驻高窗口 = 一大片隐形点击陷阱 | 只在 `:hover` 临时加高 |
| 11 | `backdrop-filter` 只能取**同一合成层内**的兄弟元素 | 桌面不属于本 WebContents 的合成图 → 无毛玻璃 | 不做毛玻璃，靠阴影 + 描边分离 |
| 12 | 对 CDP 端口 `9334` 发 `Page.navigate` | 等于把悬浮条窗口劫持成浏览器 | **永不对它发 `Page.navigate`**；验证原型用独立浏览器实例 |
