# 切片 2 范围声明

> 依《开发规范》强制 6.3：AI 每次任务先拟范围声明，交用户确认后方可动手。
> 本声明由 AI 起草，**等待用户确认**。

## 一、本片目标

让桥**真正接上宿主事件流**，并把三个纯函数内核落地（可脱离宿主单测）。完成后：

- 桥能订阅 `ctx.on('session/event')`，收到的事件进两个折叠器；
- `GET /whale/fold` 返回折叠器状态（本片实现）；
- 三个纯函数模块可独立单测，覆盖率 ≥80%；
- 架构铁律 A-1 由测试机械化看住。

**本片不碰 SSE**（`/whale/events`、`/whale/hud/events` 仍为未实现），那是切片 3。

## 二、新增文件（10 个）

### 源文件（6 个）

| 文件 | 职责 | 行数预算 |
|---|---|---|
| `whale-bridge/lib/zstd-frame.mjs` | 逐帧 zstd 解码：扫魔数 → 切片 → 解压 → 拼接 | ≤300 |
| `whale-bridge/lib/usage-stats.mjs` | token 口径：四桶求和、pressureFrom、速度窗口 | ≤300 |
| `whale-bridge/lib/fold.mjs` | 双折叠器：hudBySession（全量聚合）/ sessionFold（保留 40 条） | ≤300 |
| `whale-bridge/lib/events.mjs` | 宿主事件订阅与分发（onSessionEvent / onAgentStatus） | ≤500 |
| `whale-bridge/lib/handlers-slice2.mjs` | 本片新增路由处理器（`/whale/fold`） | ≤500 |
| `whale-bridge/lib/session-log.mjs` | 落盘会话读取兜底（定位 projectKey、逐帧解码、解析事件） | ≤500 |

**为什么拆出 `session-log.mjs`**：架构草案把落盘读取归在「zstd-frame + 事件订阅」名下，但那里还有两件事——按 `projectKey(cwd)` 规则算出会话目录、把解码结果解析成事件数组。这两件事与「逐帧解压」是不同职责，塞一起会超 300 行且违反强制 13。

### 测试文件（4 个）

| 文件 | 测什么 |
|---|---|
| `tests/unit/zstd-frame.test.mjs` | 魔数扫描、多帧拼接、空缓冲、截断帧容忍 |
| `tests/unit/usage-stats.test.mjs` | pressureFrom 口径、四桶求和、缺 cacheWriteTokens 恒 0、速度窗口过期归零 |
| `tests/unit/fold.test.mjs` | 按 seq 去重、tail 上限 40、未知事件类型跳过不抛错、phase 流转 |
| `tests/layering.test.mjs` | **架构铁律 A-1**：呈现层不得 require `@deepseek-ai/` |

## 四、明确不改动

- `whale-hud/`、`whale-window/`、`whale-button/`（后续切片）

- `tools/` 下六个闸门脚本（除必要时的路径适配）
- SSE 相关代码（切片 3）

## 五、验收口径（实测，不靠推断）

| 项 | 通过标准 |
|---|---|
| 闸门 | 六道全过，跳过 0 道 |
| 单测 | 全绿；三个纯函数模块覆盖率 ≥80% |
| A-1 | `tests/layering.test.mjs` 能抓到故意植入的违规（负向测试） |
| 逐帧解码 | 对真实会话日志解出的事件数与既有实测一致（该文件实测 562 帧 / 967 行） |
| 折叠器 | 灌入合成事件序列后，四桶累计与手算一致 |
| 未知事件 | 灌入未知类型事件不抛错，计数 +1 |
| 契约 | 折叠器不引 `fs`/`net`/`http` 等 IO 依赖 |

## 六、风险

| 风险 | 应对 |
|---|---|
| 会话日志格式与实测不一致 | 读取失败即降级为「无数据」，不猜测 |
| zstd 逐帧解码在超大文件上慢 | 本片只测小样本；性能留到切片 3 后压测 |
| `tests/unit/` 与既有 `tests/*.test.mjs` 目录混用 | 闸门 3 的 glob `tests/**/*.test.mjs` 已能覆盖嵌套 |

## 七、本片不做的事（防止范围蔓延）

- 不实现 SSE（切片 3）
- 不实现 `/whale/hud`（切片 3，它依赖 SSE 广播表）
- 不装插件进宿主
- 不拉 Electron 进程
