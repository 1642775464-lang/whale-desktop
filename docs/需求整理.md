## 一、产品是什么

一组「DSH 桌面伴侣」三件套，全部围绕「让用户在 DSH 之外也能看/用同一个会话」：

| 组件 | 形态 | 一句话 |
| --- | --- | --- |
| Whale HUD（悬浮窗） | 顶边居中常驻状态条 560×52（窗口 588×72） | 看：会话在不在跑、跑多快、上下文吃到多少 |
| Whale Window（小窗） | 屏幕右侧可拖可缩的窄窗 460×678（窗口 492×710） | 用：里面跑的是真 DSH 会话，与主窗同一条消息流 |
| Whale Bridge（桥） | DSH 宿主侧 HTTP + SSE，`127.0.0.1:19387` | 数据源：把宿主内会话事实暴露给上面两个 Electron 进程 |

三者是**三个独立 Electron / 插件进程**。入口只有一个：DSH 页面右下角的小鲸鱼按钮
（用户原话：「小窗和悬浮窗不需要右下角图标，直接把他们做成一个小鲸鱼放在 DEEPSEEK 页面这个位置，
点击就弹出悬浮窗和小窗」）。系统托盘已按用户要求移除。

## 二、六要素校验

| 要素 | 内容 |
| --- | --- |
| 痛点 | DSH 主窗被切走/最小化后，看不见会话是否还在跑、跑多快、上下文还剩多少；想发一句话必须切回主窗 |
| 目标用户 | 单机自用的 DSH Desktop 用户（本机、单人、不公开上线） |
| 使用场景 | 一边干活一边把 DSH 放在后台，用顶边细条盯状态、用窄窗随手补一句 |
| 核心功能 | 五元素状态条（鲸鱼/状态点/会话标题/tok·s/上下文占用）、悬停五行详情、多会话滚筒、收起成球、会话完成提醒、右键菜单、窄窗完整会话界面（消息流/输入区/权限档位/斜杠面板/任务清单）、切会话三档、崩溃自愈、窗口状态记忆 |
| 非目标 | 不做移动端、不做多用户、不做云端部署、不做全局热键、不做桌面毛玻璃（Windows 技术路径做不到）、不做语音/通话（能力二期） |
| 成功标准 | 悬浮窗 A1–A11 全过、小窗 B1–B14 全过，且「发小窗的消息在主窗可见」这一条端到端打通 |

## 八、已锁定为单一事实源的硬约束（首版踩坑沉淀，全部照搬，不再重新试错）

1. 必须 `--no-sandbox`：开沙箱时 GUI 初始化阶段直接崩 `0x80000003`，存活 15~20ms，连 `main.cjs` 模块体都执行不到。
2. 必须显式 `app.setPath('userData', ...)`：让 Electron 解析默认 userData 会原生崩溃，退出码 `-36861` / `0xFFFF7003`，try/catch 接不住。
3. 不要在模块顶层调 `app.getPath()`。
4. CSP 必须放行 `'self'`，否则 `<script src="hud.js">` 被静默拦截。
5. Windows 做不到桌面毛玻璃（实测内外条纹方差比 0.935），白底靠「三层阴影 + 描边」分离。
6. client 侧 JS 改完必须实地加载看 `Runtime.exceptionThrown`，`node --check` 查不出 TDZ。
7. CDP 端口 9334 就是悬浮条自己，永不对它发 `Page.navigate`。
8. 小窗必须走 `run.ps1`：宿主给子进程注入 `ELECTRON_RUN_AS_NODE=1`，PowerShell `Start-Process` 与 cmd `set VAR=` 都清不掉，只有 .NET `ProcessStartInfo.Environment.Remove()` 有效。
9. `transparent:true` + `backgroundColor:'#00000000'` + `roundedCorners:false` + `hasShadow:false`；圆角必须由「窗口透明 + CSS 裁角」共同实现；`SHADOW_PAD` 必须与 `skin.css` 的 `--shadow-pad` 完全一致。
10. 系统缩放 113% 而 `devicePixelRatio` 报 1：任何依赖 dpr 的换算错 13%，物理值必须走 HWND + `GetWindowRect`。
11. **孤儿防护已移除，不要加回来**（宿主一重启所有小窗集体自杀；正确做法是桥在卸载钩子里主动关窗）。
12. `run.ps1` 不要写 `$args`；`-Debug` 默认关闭。
13. 悬浮窗收起时把 `#whaleBtn` 物理挪到 `document.body`，用 `whaleHome={parent,next}` + `insertBefore` 还原。
14. 滚筒 `swapAt` 只改 `front`，下半程先清类再改 `back`（顺序反了有 16ms 可见窗口，闪假标题）。
15. 「进行中」判据是 `speed.phase === 'running'`，不是「最近有没有出 token」（实测一条回合里 `tool/call` 有 309 次）。
16. 滚筒两个防御机制 `reelGen`（DOM 代际号）与 `rolling`（看门狗）不能删。
17. 脉冲动效用户已明确否决，不要重新提议。

## 九、悬停详情为什么不做成常驻高窗口

Electron 的透明窗口在 Windows 上照样拦截鼠标事件（透明像素不穿透）。常驻 588×270 的高窗口
等于凭空多出一片隐形点击陷阱。所以只在悬停时临时加高，移开 180ms 内缩回，另有 3 秒兜底定时器。
