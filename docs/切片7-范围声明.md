## 二、比表面更大的两个结构性缺口

「全量复刻」不止是给四个按钮加点击处理，还缺两样地基：

### 缺口 A：命令面板是**假**的

现在面板里只有我硬编码的 3 条（`/sk`、`/skills`、语音灰项）。
而你给的图里有 **20 多条真命令**（文件 / 目标 / 计划 / 反馈 / 压缩 / 权限 / 模型 / 下载日志 / 旁问 / mnemon…）。

- 桥的 `host-ctx.listCommands(agent)` **早就实现好了，但没有任何路由用它**
- 22 条路由里**没有暴露命令列表的接口**

所以面板要显示真命令，得先有接口。这是**范围外新增**（改桥）。

### 缺口 B：模型与思考强度**没有数据源**

`/whale/models` 按 S3-D3 是**降级交付**的（空数组 + reason），因为当时不确定宿主模型目录怎么读。
要「切换模型 + 切换思考强度」，得先能列出可选模型与各自的 effort 档位。
